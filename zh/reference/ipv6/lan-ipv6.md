# Lan IPv6 分配

给 LAN 分配 IPv6 一共有三种方式:

1. SLAAC (RA 模式)
2. DHCPv6
3. 混合 (RA + DHCPv6)

![](./lanv6/edit-config.png)

## IPV6 前缀分配画布

WAN PD 中提及的 **预期上游 PD 前缀长度** 就是在此限制画布大小.

比如当前 WAN 获得前缀是 **/60** 这意味着, 你可以给下游一共分配 **16** 个 **/64** 的 **'块'**.

所以你只要在左侧选择 **对应的类型** + 在右侧 **选择一个块** 就行.
![](./lanv6/pd-edit.png)

如果不需要再给下游分配前缀, PD 部分是可以不用配置的.
